First public release of lms-mcp.

- Interactive course setup, strict configuration validation, and offline status.
- Read-only Ed discussion, reply, Lesson, and attachment synchronization.
- Four stdio MCP tools, with account identity and private posts excluded by default.
- Daily Windows scheduling, bounded retries, local edit protection, backups, and interrupted-write recovery.
- Windows, Linux, and macOS binaries for amd64 and arm64; SHA-256 checksums included.

This release provides CLI configuration rather than a GUI. Moodle is not implemented. No credentials or course data are distributed.
